辞書ヘルパーの登録（PC ごとに最初の一度だけ）

Chrome はセキュリティ上、拡張機能が PC 上のプログラムを実行することを禁止しています。 下のコマンドで「この拡張機能は辞書ヘルパーを実行してよい」と一度だけ登録すれば、 以降はすべて辞書エディターのボタンで進められます。

手順

  1. コマンドをコピー を押します。
  2. Windows キーを押し、PowerShell と入力して Enter で開きます。
  3. PowerShell の画面で右クリック（または Ctrl+V）で貼り付け、Enter を押します。
  4. 画面に Done. と表示されたら完了です。このタブとサイドパネルが自動で次の手順に進みます。

このコマンドが行うこと

  • ヘルパースクリプト（dictionary-host.ps1）を %USERPROFILE%\.udemy-ja-dictionary-helper にダウンロードします。
  • Chrome がヘルパーを見つけられるよう、現在のユーザーのレジストリにキーを 1 つ書き込みます。管理者権限は不要です。
  • 何もインストールしません。GitHub CLI のインストールとログインは、辞書エディターでボタンを押して承認したときだけ行われます。

内容を先に確認するには register.ps1 を開いてください。
