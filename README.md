# Japanese Translator for Udemy

Udemy를 **일본어**로 보여 주는 Chrome 확장 프로그램입니다.

- **퀴즈와 시험**: 영어 문제와 보기 옆에 일본어 번역이 나옵니다.
- **강의 영상**: 영어 자막이 일본어 자막으로 바뀝니다.

번역은 Chrome에 내장된 Translator API(영어 → 일본어)로 내 컴퓨터 안에서 이루어집니다. 가입, 결제, 별도 프로그램 설치가 필요 없습니다.

> 이 프로젝트는 [JaceDashS/udemy-korean-translator](https://github.com/JaceDashS/udemy-korean-translator)(Korean Translator for Udemy)를 일본어용으로 옮긴 버전입니다. 자세한 내용은 [원작과 출처](#원작과-출처)를 보세요.

---

## 준비물

- 컴퓨터용 **Chrome** 브라우저 (버전 138 이상)
- **Udemy** 계정과 수강 중인 강의
- (선택) **GitHub** 계정: [단어장](#단어장-선택)에 단어를 등록할 때만 필요합니다. 번역만 쓸 때는 없어도 됩니다.

> Chrome 버전 확인: Chrome 오른쪽 위 **⋮** → **도움말** → **Chrome 정보**.

---

## 설치하기 (처음 한 번만)

### 1단계. 파일 내려받기

<p align="center"><img src="docs/images/readme/github-code.png" width="420" alt="GitHub에서 Code 버튼과 Download ZIP을 표시한 화면"></p>

1. 이 페이지 위쪽의 초록색 **Code** 버튼을 누릅니다. **①**
2. **Download ZIP**을 누릅니다. **②**
3. 내려받은 ZIP 파일의 압축을 풀고, 폴더를 찾기 쉬운 곳(예: 문서 폴더)으로 옮겨 둡니다.

> ⚠️ 이 폴더는 **지우거나 옮기지 마세요.** 지우면 확장 프로그램이 사라집니다.

### 2단계. Chrome에 추가하기

<p align="center"><img src="docs/images/readme/extensions-buttons.png" width="720" alt="Chrome 확장 프로그램 화면의 Load unpacked 버튼과 Developer mode 스위치"></p>

1. Chrome 주소창에 `chrome://extensions` 를 입력하고 Enter를 누릅니다.
2. 오른쪽 위 **개발자 모드**(Developer mode) 스위치를 켭니다. **①**
3. **압축해제된 확장 프로그램을 로드합니다**(Load unpacked) 버튼을 누릅니다. **②**
4. 1단계에서 압축을 푼 폴더를 선택합니다.
5. 목록에 **Japanese Translator for Udemy** 카드가 보이고 스위치가 켜져 있으면 설치 끝입니다.

> 한국어판(Korean Translator for Udemy)과 확장 ID·사전 도우미 이름이 다르므로 두 확장을 함께 설치해도 서로 충돌하지 않습니다.

## 사용하기

### 퀴즈와 시험

Udemy에서 퀴즈나 연습 시험을 열면 문제와 보기 오른쪽(창이 좁으면 바로 아래)에 일본어 번역이 나옵니다. 시험 제출 후 **결과 화면**(정답, 해설)도 번역됩니다. 해설 번역 앞에는 `解説` 라벨이 붙습니다.

> 💡 **처음 한 번은** 일본어 번역 모델을 내려받느라 1~2분이 걸릴 수 있습니다. 번역이 나오지 않으면 페이지 아무 곳이나 **한 번 클릭**하고 잠시 기다려 주세요.

### 강의 영상

1. 강의 영상의 **자막(CC)** 을 **영어**로 켭니다.
2. 영어 자막 자리에 **일본어 자막**이 나옵니다.
3. 영상 오른쪽 위의 **日本語字幕 オフ ×** 버튼을 누르면 영어 자막으로 돌아갑니다. 다시 누르면(**日本語字幕 開始**) 일본어 자막이 켜집니다. 끈 상태는 다음 강의에서도 유지됩니다.

> 영상을 **전체 화면**으로 키우면 영어 자막이 그대로 나올 수 있습니다. 전체 화면을 끄면 일본어 자막이 다시 보입니다.

## 단어장 (선택)

"EC2", "private subnet" 같은 용어는 번역하지 않고 **영어 그대로** 두는 편이 이해하기 쉽습니다. 이런 단어 목록이 이미 들어 있고, 직접 추가할 수도 있습니다. 단어 목록은 이 리포지토리의 `dictionary` 브랜치(`dictionary.json`)에서 읽어 옵니다.

1. Chrome 툴바의 확장 프로그램 아이콘을 누르면 사이드 패널에 단어장(辞書エディター)이 열립니다.
2. **単語**(단어)를 쓰고 **追加**(추가)를 누릅니다. **意味**(뜻)에 일본어를 쓰면 번역에 그 뜻이 들어가고, 비워 두면 영어 그대로 나옵니다.
3. **登録**(등록) 또는 **登録申請**(등록 신청) 버튼을 누릅니다. 처음 한 번은 버튼이 순서대로 안내합니다(Windows 전용: PowerShell, GitHub CLI 사용).
   - 리포지토리 소유자는 바로 **登録完了**, 다른 사용자는 Pull Request로 **登録申請完了**가 됩니다.

## 문제가 생겼을 때

| 증상 | 해결 방법 |
| --- | --- |
| 번역이 전혀 나오지 않아요 | Udemy 페이지를 **새로고침**하세요. 그래도 안 되면 페이지를 한 번 클릭하고 1~2분 기다리세요. Chrome 138 이상인지도 확인하세요. 개발자 도구 콘솔에 `[Japanese Translator]` 로그가 나옵니다. |
| 영상에 일본어 자막이 안 나와요 | 자막(CC)이 **영어로 켜져 있는지** 확인하세요. 오른쪽 위 버튼이 **日本語字幕 開始**이면 한 번 누르세요. |
| 확장 프로그램이 사라졌어요 | 압축을 푼 폴더를 지우거나 옮기지 않았는지 확인하고 2단계를 다시 해 주세요. |

## 새 버전으로 바꾸기

1. ZIP을 다시 내려받아 기존 폴더에 **덮어쓰기**로 압축을 풉니다.
2. `chrome://extensions` 에서 **Japanese Translator for Udemy** 카드의 새로고침 버튼(↻)을 누릅니다.
3. 열려 있던 Udemy 페이지를 새로고침합니다.
